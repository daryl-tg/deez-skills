# deez-skills

Central hub for every skill, command, and subagent, shared across Claude Code
and Codex on every device.

Status: framework only. No skills have been migrated yet — `registry.toml` is
intentionally empty of entries, and nothing is linked into `~/.claude` or
`~/.codex`.

This file is regenerated by `bin/index` once entries exist. Do not hand-edit
below this line.
