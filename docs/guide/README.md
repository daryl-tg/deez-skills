# The guide

Eleven short chapters. **Start with chapter 0** the first time. It is the
ordered checklist. The rest are reference.

   per-repo verification step people skip.
1. [Setup](./01-setup.md). What the install commands mean and what to check.
2. [The router](./02-the-router.md). What `$clanker-mode` does, what every
   delegate reads first, and when to use it.
3. [Principles](./03-principles.md). How rules are cited instead of restated.
4. [Verification](./04-verification.md). The two lanes, and what counts as proof.
5. [Delivery](./05-delivery.md). Rebase, promote, PR, squash.
6. [Two runtimes](./06-two-runtimes.md). Claude hosts the router, Codex support
   is dormant.
7. [Making it yours](./07-making-it-yours.md). Adding, merging, retiring skills.
8. [Recipes](./08-recipes.md). The short version of common tasks.
9. [Keeping it honest](./09-keeping-it-honest.md). When to run the maintenance
   pass, and why not daily.
10. [super-clanker](./10-super-clanker.md). The local Router that runs
    clanker-mode Workers from events.

Prefer to learn by doing? Chapter 0, then [recipes](./08-recipes.md).
