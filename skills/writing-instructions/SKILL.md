## Scope

Use this workflow for instructions, guidelines,
skills, and other documents that tell an agent or
human what to do.

Not for prose-style cleanup.

## Workflow

1. Start with the principle or decision rule.
2. Add examples only when they define a convention or
   boundary the reader would not infer.
3. Remove exhaustive lists, bad examples, and tool
   explanations that restate what the reader already
   knows.
4. Keep the main document short and move bulky detail
   elsewhere when progressive disclosure helps.
5. Re-read each sentence and ask whether it changes
   behavior or just adds bulk.

## Rules

- State the principle, not all its instances.
- Keep specifics only when they prevent divergence.
- Do not explain familiar tools unless the point is
  when to use them.
- Do not spell out consequences the reader already
  understands.
